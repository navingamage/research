## Screener's top 3

1. https://github.com/odoo/odoo :: POS 'Exchange' at the till: four independent silent traps across core, pos_discount (onDoRefund patch plus the auto-reapply listener), pos_loyalty (reward maths over refund lines) and the Python invoice path (is_refund to out_refund). All are verified at the pin, none is checkable with mocked hoot tests, and the feature is absent at master e04968ab.
2. https://github.com/opensearch-project/OpenSearch-Dashboards :: Per-panel time range and refresh interval: verified silent global-timefilter reads in four separate paths (PPL interceptor, Timeline buildOptions axis bounds, applyFilter '*' brushing, getAutoRefreshFetch$ in each embeddable). The obvious input.timeRange path looks correct in each embeddable. The prompt needs trimming under 160 words.
3. https://github.com/nextcloud/server :: Read-only / No-download badges: a structural trap pair, verified in @nextcloud/files 4.0.0 (WRITE=CREATE=4, 'NV'->UPDATE). DAV and OCS-built nodes give the same bits different meanings, so any single-bit predicate fails either DAV share-mount roots or OCS received-edit files, and SharingService's nodes[0] merge breaks the direct-plus-group example.
