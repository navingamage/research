One of the junior engineers on my team has put up a change that adds automatic retries to our refund service, and I need to review it before it goes anywhere near production. In Visual Studio Code I'll go through the changed files in the Source Control view and read the diff, then run the existing tests from the Testing panel. I'm worried a retry after a timeout could refund a customer twice, so I'll add one small test that shows it, run it and see it fail. Then in Google Docs I'll write my review feedback for the engineer: what they did well, what has to change before merge, and one thing to learn from it. Deliverables are the new failing test file and the review feedback as a PDF.
